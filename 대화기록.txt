프로젝트 요구사항
═══════════════════════════════════════════════════════════════════════════════

3. 기능 요구사항

3.1 회원 기능
3.1.1 회원가입
  - 아이디, 비밀번호, 닉네임, 이메일(선택)을 입력받음

3.1.2 로그인
  - 아이디와 비밀번호로 로그인
  - 세션 또는 토큰 발급

3.1.3 로그아웃
  - 로그인된 사용자만 가능

3.2 비회원 기능
3.2.1 채팅방 목록 조회 (비회원도 가능)
  - 채팅방 제목, 현재 접속 인원, 공개 여부 확인 가능

3.2.2 기능 제한 (비회원 불가)
  - 채팅방 생성, 입장, 채팅 작성, 신고, 프로필 확인

3.3 채팅방 기능
3.3.1 채팅방 생성 (회원만)
  - 제목, 설명, 공개 여부, 비밀번호 설정, 최대 인원 수 입력 가능

3.3.2 비밀번호 채팅방
  - 비밀번호 설정 가능
  - 입장 시 비밀번호 확인

3.3.3 채팅방 입장 (회원만)
  - 공개방 또는 비밀번호 인증 후 입장 가능

3.3.4 채팅방 퇴장
  - 자유롭게 퇴장 가능

3.3.5 채팅방 삭제
  - 방 생성자만 삭제 가능

3.4 실시간 채팅 기능
3.4.1 메시지 전송
  - 작성자 닉네임, 메시지 내용, 작성 시간 포함

3.4.2 메시지 수신
  - 채팅방 참여자가 실시간 수신

3.4.3 시스템 메시지
  - 사용자 입장/퇴장, 강제 퇴장, 관리자 경고 시 출력

3.5 신고 기능
3.5.1 채팅방 신고 (회원만)
  - 신고 사유: 욕설, 음란물, 도배, 불법 홍보, 사기 의심

3.5.2 신고 저장
  - 관리자 페이지에서 확인 가능

3.6 관리자 기능
3.6.1 관리자 로그인
  - 별도의 관리자 권한 계정으로 로그인

3.6.2 전체 채팅방 조회
  - 모든 채팅방 목록 조회 가능

3.6.3 강제 입장
  - 비밀번호 여부와 관계없이 모든 채팅방 입장 가능

3.6.4 채팅방 삭제
  - 신고 누적, 불법 콘텐츠, 운영 정책 위반 시

3.6.5 회원 경고 기능
  - 경고 횟수, 사유, 일시 저장

3.6.6 회원 제재
  - 채팅 제한, 일정 기간 정지, 영구 이용 제한

프로젝트 구조
═══════════════════════════════════════════════════════════════════════════════

라우팅 구조:
  / - 홈 (채팅방 목록) - 누구나 접근 가능
  /login - 회원 로그인
  /signup - 회원가입
  /admin/login - 관리자 로그인
  /chat/:roomId - 채팅방 상세 (회원만 접근 가능 - ProtectedRoute)
  /admin - 관리자 대시보드 (관리자만 접근 가능 - AdminRoute)

인증 흐름:
  1. AuthContext에서 user, admin 상태 관리
  2. 로그인/회원가입 시 localStorage에 저장
  3. 페이지 새로고침 시 자동으로 복구
  4. ProtectedRoute와 AdminRoute로 접근 제한

상태 관리:
  AuthContext
    - user: 현재 로그인한 사용자 정보
    - admin: 현재 로그인한 관리자 정보
    - login(), logout(), signup(), adminLogin(), adminLogout()
    - isLoggedIn, isAdmin 플래그

  ChatContext
    - chatRooms: 채팅방 목록
    - currentRoom: 현재 접속한 채팅방
    - messages: 메시지 목록
    - fetchChatRooms(), enterChatRoom(), leaveChatRoom(), createChatRoom()
    - sendMessage(), addMessage() 등
